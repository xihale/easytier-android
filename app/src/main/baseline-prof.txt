# Baseline Profile（手工规则版）
#
# 作用：首次启动与首次滚动时，下列热路径代码已预编译（JIT→AOT），显著降低首帧卡顿。
# 打包时 AGP 会把本文件编进 APK assets/dexopt/baseline.prof，
# 由 profileinstaller 在设备上安装（Android 9+ 运行时安装，7~8.x 安装期编译）。
#
# 规则语法：
#   HSPL<...>->**(**)**  方法 Hot/Startup/PostStartup 编译
#   L<class>;            类加载
# 规则覆盖收窄为启动与稳定态热路径：全量 ** 通配会把未用到的图标、对话框等
# 一并编进 OAT，白白膨胀 compiled-classes 与安装体积。
# 更精细的规则可用 :baselineprofile 模块在真机上自动生成后替换本文件。
